# Seed: メモAPIの実装 (デモ)

## 背景
社内ツール用のシンプルなメモAPIが必要。現在は health と一覧取得だけが実装されている。

## 参照材料
- (なし: 要件はこの文書にすべて含まれる)

## 実装してほしいこと
1. **メモ作成** `POST /notes`
   - body: `{"title": "...", "body": "..."}`
   - 成功: 201 + 作成されたメモ JSON (id 連番, 1始まり)
   - title が空 / 101文字以上 / 文字列でない → 400 + `{"error": "..."}`
2. **メモ削除** `DELETE /notes/<id>`
   - 成功: 200 `{"ok": true}`、以後 GET で 404
   - 存在しない id → 404
3. **一覧・詳細は既存のまま動くこと** (退行防止)

## 受け入れ基準
- 上記がすべて HTTP で確認できること
- 既存の単体テスト (`python3 -m unittest`) が壊れないこと
