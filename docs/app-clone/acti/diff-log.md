## 録画との差分（意図的）
| 箇所 | 差分 | 理由 |
|---|---|---|
| 名称・ロゴ・文言・アイコン | 仮のものに置き換え | 権利上コピーしない（assets-todo.md） |
| Act 詳細の「Try It」 | 本家はデモのチャットに遷移する可能性が高いが、シートで入力 → 実行 → 結果を表示 | 未録画のため、試しやすい形にした |
| 音声入力 | 固定の文章を返すモック | キーボード拡張はマイクを使えない |

## 2026-11-09 ユーザーのフィードバック「忠実でない・品質が低い・リキッドグラスが不適切」
| 差分 | 原因 | 修正 |
|---|---|---|
| 背景が青く光っていた | ブランド色を背景に敷いた | 録画のフラットな `#11161D` に戻した |
| 主ボタンが青いガラス | ガラスを主ボタンにも掛けた | 録画どおり白の不透明 |
| カード・リスト・キーボードまでガラス | ガラスの使い方を誤った | 浮く操作部品だけに限定し、内容が下を流れて透けるレイアウトに変更 |
| 文字が大きく太い | 推定値のまま | 録画と並べて再計測し、見出し 18pt Medium・行 16pt などに修正 |
| Act アイコンが記号 | SF Symbols + 濃いグラデーション | パステルの球 + 絵文字で立体感を再現 |
| 設定アイコンが白一色 | 未計測 | 白線 + 青の2色に |
