# Acti 再現: 差分ログ

実装と録画の差分、推定で埋めた箇所、ビルドで見つかった問題を記録する。

## 推定で実装した箇所（録画なし）
| 箇所 | 根拠 | 確認方法 |
|---|---|---|
| 実アプリ上のキーボード（通常入力・キーの寸法・長押し候補） | デモ画面の擬似キーボード（57–75s）から寸法と色を流用 | i05〜i07 の録画 |
| Acts タブ（Act Panel）のレイアウト | 公式ガイド「Acts are reusable workflows…」の説明 | i10 の録画 |
| Voice パネル | 公式ガイドの説明（Transcribe / Ask AI / Translate to / 絵文字） | i12〜i13 の録画 |
| Clips パネル・Clips 設定 | Desktop ページの説明 | i19 の録画 |
| Act Builder Agent のチャット | Acti Agent ページの説明（プラン提示 → 修正 → テスト → 保存） | i15 の録画 |
| 検索・Community のインストール / Remix | Acts ガイドの説明 | i18 の録画 |
| 設定の Language / Clips / Execution History / Connected Tools / Feedback / About | 項目名のみ録画で確認 | i20 の録画 |
| ペイウォール | App Store の価格のみ。画面は未確認 | i24 の録画 |
| ライトモードの色 | 録画はダークのみ | i26 の録画 |

## 録画との差分（意図的）
| 箇所 | 差分 | 理由 |
|---|---|---|
| 名称・ロゴ・文言・アイコン | 仮のものに置き換え | 権利上コピーしない（assets-todo.md） |
| Act 詳細の「Try It」 | 本家はデモのチャットに遷移する可能性が高いが、シートで入力 → 実行 → 結果を表示 | 未録画のため、試しやすい形にした |
| 音声入力 | 固定の文章を返すモック | キーボード拡張はマイクを使えない |
