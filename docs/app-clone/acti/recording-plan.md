# Acti 録画計画

> **スコープ（2026-11-09 ユーザー決定）: iPhone のみ。有料範囲はスキップ。** Mac 版と Pro 関連は録画・再現しない。

**録画ルール**
- 1フロー = 1ファイル。ファイル名は `<番号>-<フロー名>.mov`（例: `i05-keyboard-basic.mov`）
- 操作はゆっくり。長押し・ドラッグ・ホバーは 1〜2 秒止める
- iPhone: コントロールセンターの「画面収録」。**キーボードが映るよう、メモ帳などの入力欄で操作**する
- 個人情報・本物のメールやカレンダーは映さない（ダミーの Google アカウント推奨）
- ライト / ダークの差分は、主要画面だけ両方撮れば十分

区分: 無料 = 承認なしで録画OK / 有料 = 承認が必要
